# Pistes pour la suite de Notes

## Cap

Notes est un espace personnel de connaissances : privé, fiable, en Markdown, simple à utiliser et puissant pour ranger, relier et retrouver ses notes.

L'application ne cherche pas à devenir un outil qui fait tout.

## Améliorations proposées

### 1. Renommer le mode Pro

Renommer le **Mode Pro** en **Mode avancé**. Il ne s'agit pas d'un abonnement ni de fonctions payantes, mais d'une interface plus dense pour les usages avancés.

### 2. Résolution de conflits façon Git

Quand deux appareils modifient une même note, proposer une résolution de conflit qui compare :

- la version commune de départ ;
- la version distante ;
- la version locale.

L'utilisateur peut fusionner les changements au lieu de devoir copier son texte puis recharger la note.

### 3. Faire de la racine un meilleur Finder

La racine est déjà l'endroit des notes sans dossier : pas d'Inbox séparée.

L'améliorer comme un Finder avec :

- tri des notes ;
- filtres ;
- recherches sauvegardées ;
- dossiers virtuels fondés sur ces recherches.

### 4. Approfondir les liens entre notes

- Montrer les liens non résolus ou ambigus.
- Pouvoir lier directement un titre dans une note.
- Gérer des alias pour une note.
- Inclure une note dans une autre lorsque cela reste compatible avec le Markdown et l'export.
- Rendre les liens entrants plus utiles avec leur contexte.

### 5. Navigation et confort d'écriture

- Historique retour / avance entre les notes visitées.
- Continuer à raffiner l'éditeur et la navigation dans les notes.

### 6. Pérennité des données

- Continuer la compatibilité avec Obsidian et le Markdown courant.
- Export ciblé d'un dossier ou d'une sélection.
- Éventuellement gérer des pièces jointes autres que les images.

## Hors périmètre

- Notes quotidiennes / journal.
- Tâches, calendrier et gestion de projet.
- IA.
- Plugins.
- Collaboration et publication.
